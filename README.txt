IMPORTANTE SOBRE SEGURANÇA
Este login é apenas uma etapa de protótipo/configuração. Ele NÃO deve ser considerado segurança de produção, porque os dados e a credencial ficam no navegador. Para colocar o link público na bio e permitir que você administre de qualquer aparelho, a próxima etapa é conectar o projeto a um backend (Firebase ou Supabase), com autenticação e banco de dados. Depois disso, os produtos e fotos ficam online e o acesso de administrador é realmente protegido.

COMO TESTAR
1. Abra index.html para ver a loja.
2. Abra admin.html para entrar no painel.
3. Cadastre um produto com foto.
4. Volte para index.html no mesmo navegador e veja o produto.

OBSERVAÇÃO
As fotos no protótipo são convertidas para dados no navegador. Muitas fotos grandes podem ocupar bastante armazenamento local. A versão online resolverá isso usando armazenamento em nuvem.
